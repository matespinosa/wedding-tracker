# Direcciones visuales

Archivos fuente del canvas de diseño que se usó para escoger el estilo de la app.
Cada `.dc.html` es un artboard; `canvas.json` los acomoda y define las notas.

| Archivo | Dirección |
|---|---|
| `DireccionA.dc.html` | Papelería editorial — marfil, Cormorant, olivo |
| `DireccionB.dc.html` | Tablero denso — kanban por estado |
| `DireccionC.dc.html` | Terracota mobile-first — 390×844 |
| `DireccionD.dc.html` | Nocturno champagne — negro y dorado |
| `Main.dc.html` | Candidata que va adelante (A), pantalla completa |

Los números que aparecen (120 invitados, 86 confirmados, 34 por confirmar) son de
ejemplo, y la fecha quedó como `[Fecha de la boda]`. Una vez elegida la dirección,
`Main.dc.html` se queda con el diseño final y los bocetos descartados se retiran.
